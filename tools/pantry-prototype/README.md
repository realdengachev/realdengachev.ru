# Pantry — прототип и скринкаст для ленты кейсов

Главный экран приложения Pantry по фрейму Figma `83:1297`: фото из верхней стопки перетаскивается в папку, пока оно в руке — изгибается как платок (WebGL). Отсюда же записывается видео для карточки на сайте.

## Команды

```bash
cd tools/pantry-prototype
npm install          # puppeteer-core + ffmpeg-static, только для записи
npm run serve        # http://127.0.0.1:5288
npm run record       # перезаписать видео и постер для сайта
```

`npm run record` использует установленный Google Chrome (`/Applications/Google Chrome.app`), другой путь — через `CHROME_PATH=...`. Запись идёт около минуты и сразу перезаписывает:

- `public/video/pantry.mp4` — 540×1148, 60 fps, H.264, бесшовный цикл 7.4 с;
- `src/assets/img/pantry-poster.png` — постер (кадр 110: экран собран, касания ещё нет).

Карточка в ленте: `kind: 'phone-video'` в `src/data/content.ts`, разметка — `src/components/GalleryCard.astro`.

## Режимы страницы

| Адрес | Что показывает |
| --- | --- |
| `/` | интерактивный прототип в рамке iPhone 16 Plus |
| `/?demo` | сценарий скринкаста по кругу в реальном времени (без рамки) |
| `/?demo&record` | то же на виртуальных часах — кадры шагает `record.mjs` |
| `/?overlay` | эталон из Figma поверх вёрстки (50%) для сверки |

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html`, `styles.css` | вёрстка экрана в единицах макета (385×819) |
| `app.js` | раскладка из Figma, жесты, пружины, папки и счётчики |
| `cloth.js` | WebGL2-рендер «платка»: сетка, шум, инерция, свет и тень |
| `demo.js` | сценарий: запуск → касание фото с матчей и удержание → перенос в Weekends → заставка |
| `clock.js` | виртуальные часы для `?record` (rAF, таймеры, CSS/WAAPI-анимации) |
| `record.mjs`, `serve.mjs` | запись видео и локальный сервер |
| `assets/` | картинки и векторы, выгруженные из Figma |
| `ref/` | эталонные рендеры фреймов из Figma |

## Что подкрутить

- **Сила изгиба** — `cloth.js`, строка с `this.opts`: `zAmp` — глубина волн, `xyAmp` — волнистость краёв, `persp` — сила перспективы (меньше — сильнее).
- **Тайминги ролика** — `demo.js`, функция `cycle()`: шаги привязаны к абсолютному времени от начала цикла, `CYCLE` — общая длина. Первый и последний кадр — заставка, поэтому цикл бесшовный.
- **Кадр постера** — `POSTER_FRAME` в `record.mjs`.

## Шрифт

Вёрстка рассчитана на Lebowski by Pragmatica, установленный в системе. Без него страница возьмёт Archivo, и ширина текста немного изменится. Перед записью проверьте, что шрифт установлен: в видео текст запекается тем шрифтом, который был в системе.
